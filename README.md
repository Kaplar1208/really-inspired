# Really Inspired

Módulo para Foundry VTT (sistema dnd5e) que gestiona la Inspiración con:

- Pool compartido o inspiración individual por jugador (configurable).
- Máximo de inspiración configurable.
- Cesión de inspiración entre jugadores mediante click derecho en mensajes de chat.
- Sincronización transparente con la Inspiración vainilla del sistema (límite 1: `>0` se refleja como activa, `0` como inactiva).

## Requisitos

- Foundry VTT v13+
- Sistema dnd5e v3+
